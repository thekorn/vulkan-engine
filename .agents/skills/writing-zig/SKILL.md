# Writing Zig for Vulkan Engine

Use Zig 0.17, with `0.17.0-dev.2251+1175a3e99` as the minimum version.
Any Zig 0.17 version at or above that minimum is allowed; an exact
nightly is not required.
Run commands through `devenv shell -- ...` for a consistent toolchain;
do not assume APIs from another Zig release.

## Verify the Toolchain

Run `devenv shell -- zig version` before diagnosing version-sensitive
compiler errors. Use `zig env` to locate the active standard-library
source and inspect it directly when an API is uncertain.

## Project Conventions

- Use `std.Io` APIs (`std.Io.Dir`, `std.process.Init`, and explicit
  `Io` values) rather than removed global I/O APIs.
- C declarations are generated by `build.zig` with `addTranslateC`.
  Import or re-export the generated `c` module; do not use the removed
  `@cImport` builtin.
- `@typeInfo(T).@"struct"` exposes parallel `field_names` and
  `field_types` arrays in this compiler revision.
- Keep SIMD math in `math.Vec2` / `Vec3` / `Vec4` / `Mat4`, but use
  the matching `*Storage` fixed-size arrays for C and Vulkan ABI
  fields. Convert matrices with `math.mat4ToStorage()` before upload.
- Preserve explicit 16-byte alignment on std140/std430 UBO and
  push-constant fields.
- Unmanaged collections receive the allocator at mutation and deinit
  calls.
- Prefer the build-integrated dependency APIs already used in
  `build.zig`; do not add a shell wrapper when a build step owns the
  behavior.

## Coverage-Sensitive Builds

`zcov` sets `root_module.fuzz = true` on the test artifact. Coverage
runs must use Zig's compiler-provided test runner, link
`zig-cov-rt.o`, enable LLVM and libc, and keep sanitizer coverage off
the project's C++ translation units. Ordinary tests retain the custom
runner.

## Required Verification

```bash
devenv shell -- zig build test --summary all
devenv shell -- zig build lint
devenv shell -- codebook-lsp lint --unique -s .
```

For coverage changes, also run:

```bash
devenv shell -- zig-cov test --format=html --output=coverage.html -- --summary all
```
